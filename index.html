Ubuntu Google Drive Sync

A personal Google Drive synchronization setup using rclone on Ubuntu. It keeps the owner's local GoogleDrive folder and Google Drive files synchronized in both directions.

The desktop application runs on the owner's computer. Google OAuth is used to let that local application access the owner's Google Drive. This website contains information about the setup and does not provide a file upload, sign-in service, or synchronization server.

This application is for the owner's personal use. It is not a Google product and is not offered as a public synchronization service.
