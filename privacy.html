Privacy information

Ubuntu Google Drive Sync is the owner's personal rclone-based desktop synchronization setup. This page describes that setup as configured on 19 October 2026.

Google Drive access

The local application requests permission to view and manage Google Drive files so it can list, download, create, update, rename, and delete files as needed for two-way synchronization. Google Drive file contents and metadata pass between Google's services and the owner's computer. The application does not use a separate application-operated synchronization server.

Local storage

Synchronized files are stored in the owner's local GoogleDrive folder. OAuth credentials, synchronization listings, logs, and retained local file versions are stored on the owner's computer. Logs and synchronization records can include file names and paths. These are not published by this website.

Sharing and use

The synchronization setup uses Google user data to maintain the owner's file copies. It has no advertising, sale of Google user data, or application analytics integration. Its Google Drive data is not used to train machine learning models. The setup does not intentionally send synchronized files or OAuth tokens to the documentation host.

This documentation website

These static pages contain no sign-in flow, upload form, cookies set by the application, or analytics scripts. The website host may process ordinary web request information under its own privacy terms.

Stopping access and removing data

The owner can stop synchronization on their computer and revoke the application's Google Account connection at Google Account connections. Revoking access does not erase previously synchronized local files. Local files, retained versions, logs, and credentials must be removed separately if no longer wanted. Stop synchronization before removing local copies to avoid propagating deletions.
